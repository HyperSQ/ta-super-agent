# DSH 助教会话

适用于 DeepSeek Harness 0.2.1-rc.2 的桌面/Web 配置。插件和助教服务需要一起更新。

1. 打开 DSH 左栏「插件」，用「添加插件」的本地路径选项安装本目录。
2. 打开「插件 → 已安装插件 → 助教服务器连接」，在详情的「助教服务器连接」组件旁点击「配置」。填写服务器、SSH 用户名、密码和已经核对过的服务器指纹，再点「保存连接参数」。内核目录默认 `/opt/ta-super-agent`。默认端口 18787，服务器 `.env` 中的 `PORT` 优先。密码输入框留空会保留已保存的密码。
3. 在新建会话的预设选择器选「助教会话」。要开普通窗口，仍选原来的「标准」或自己的原有预设。插件不会更改默认预设，已有会话继续使用原配置。

助教会话可照常本地读写文件、执行命令和整理讲义。只有调用助教工具时才建立 SSH 连接。查课程和作业走只读接口。联系服务器时，工具只上传转交的具体请求，返回事件编号；用 `ta_request_status` 查状态或结果。派发会先显示 QQ 群号和通知原文，经 DSH 人工确认后交给服务器 Router 及现有交付队列；排队与已发是不同状态。

SSH 密码在 DSH 设置表单中按密钥字段隐藏，保存后由 DSH 的本机配置持久化。插件只通过 SSH 转发访问助教内核，密码和服务器管理令牌不进入工具参数或返回值。

## 查询班级近况

在助教会话中可以问「数分班最近一周都在问什么？结合最近作业列出习题课重点」。工具读取服务器当前课程进度、教材标识、最近作业的线下登记统计、机器人记录的公开群消息和有效学习记录。按 QQ 号可以筛公开群活动，按课程名单姓名可以查个人登记、成绩和实际截止时间。QQ群记录为助教已接收的数据，QQ 号和名单姓名分别查询。学生私信及延期原因不在此接口中。

## 助教会话的教学工具

- 通过「默认课程 ID」为助教会话预加载最近 7 天的简报，包括公开群消息、作业、学习观察和已记录的教师交流。留空时按需查询；普通会话不会加载。切换课程时请在工具里明确指定。
- `ta_read_messages` 可读取课程绑定群和该课教师交流，普通群文字从本次上线起记录。未提及机器人的消息只入库，不触发答复。学生私信不出现在 DSH。
- `ta_save_assignment` 和 `ta_record_score` 使用工作台的正式数据，附教师确认。
- 给群发练习时，`ta_render_image` 同时返回预览图和 imageId。用支持图片输入的模型检查预览，再用 `ta_send_group` 提交同一张图。要复查已有图片时用 `ta_view_image`。
- 新发的公式解答会保存实际发出的图片。DSH 用消息 ID 找图，QQ 助教处理引用追问时可读图。旧回复只能读取已保存的原稿。
- `ta_textbook` 通过同一个业务入口查教材编号、主题、节范围和原 PDF 页，结果与服务端助教使用同一课程资料。
- `ta_assignments` 可列出作业，也可以按作业 ID 查详情。需要核对图片时再填题图序号，详情默认只附题图目录。
- `ta_read_messages` 会标出已记录的课程图片和文件。用 `ta_read_attachment` 按消息及序号打开，最大 3 MiB。普通文件会提供可读取的本地路径；能否下载取决于 QQ 原附件是否仍可用。
- `ta_ask_teacher` 经确认后私信课程定时任务中配置的唯一教师。教师需在 QQ 引用该消息回复，再用 `ta_request_status` 查询答复。
- `ta_task_memory` 查询本课程服务器上的讲义或定时材料任务，返回当前版本、产物摘要和修改记录。通过 `ta_revise_task` 确认后修改同一任务，保持原任务 ID。需要服务端任务连续性接口。
- `ta_course_conversation` 查询或继续课程教师在 QQ、助教工作台和 DSH 之间的对话。服务端确定教师身份关联。仅转交当前请求，普通 DSH 会话不加载该工具。
- 文件制作可以用 DSH 的原生文件和命令工具。文件准备好后统一通过 `ta_send_group_file` 上传到课程绑定群，支持 ZIP、PDF、DOCX、Markdown 和 TXT，单文件最大 10 MiB。确认卡展示文件名、大小和目标群，上传结果可用 `ta_request_status` 查询。

## 维护名单

在助教会话中附上 XLSX 或 UTF-8 CSV，说明「把这份名单导入数学分析 B3」。多列文件请用「姓名」作为表头，最多 2 MiB。导入会追加姓名并按全名去重。可直接要求增加学生。删除时确认卡会显示课程和学生姓名，确认后才会移除，已有作业记录仍可查。

用教师 QQ 时，先私聊助教并确认当前课程，再发送带「姓名」列且文件名含「名单」的文件，也可在同一条消息注明「导入名单」。可使用 `/roster add 张三`、`/roster remove 张三`；删除需用同一教师 QQ 回复助教返回的一次性确认指令。
