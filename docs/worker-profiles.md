# 助教 Worker 职责

| 职责 | 来源和执行 | 工具与结果 |
|---|---|---|
| 答疑 | QQ 答疑与 DSH 问答走现有 QA Worker | 只读课程、教材与消息上下文。按既有工具回复规则交付。 |
| 教学事务 | 已配置的教师在 QQ 私聊新建或编辑作业、登记成绩和确认草稿，Router 创建独立任务。同课程事务按队列顺序处理。 | 复用已有作业与记分服务。业务写入和该任务的 QQ 回执在同一个数据库事务提交。 |
| 作业处理 | 收件服务在归档邮件时写入系统事件，Router 为每封新邮件派发一个独立任务。 | 读取本课程邮件、名单及可见作业，给出带说明的候选。学籍身份、正式登记和外发仍走工作台审批；候选匹配不读取手写内容。 |
| 教学材料 | 保留原讲义入口、自定义计划与定时执行。计划显式选择原执行器或 Linux DSH。 | DSH 使用课程和任务独立的会话、目录和计划工具许可，支持教师回复后继续和文件交付。 |

教师现有的名单、课程进度等结构化指令以及学生 QQ 提交与延期仍由原业务服务处理。工作台「运行任务」显示 Worker 职责，「后台活动」中的 `worker.start` 记录角色。旧任务可根据原有类型读取，无需迁移任务历史。
