## 本轮验收 05

1. 在课程设置里确认有至少两名学生，从「作业管理」给一份作业打开「延期」。
2. 给第一名学生设置一个晚于全班截止的时间，保存并重新打开。核对个人时间和备注已保存，全班截止及另一学生不变。
3. 修改该生的延期时间。再尝试填写等于或早于全班截止的时间，应显示校验错误。
4. 撤销延期。该生回到全班截止时间，其他学生和已有分数不变。

## 讲义草稿验收 08

1. 选择课程，从「运行任务 → 准备习题课讲义」提交「40 分钟，围绕一致收敛准备 3 道习题」。
2. 刷新后展开讲义任务。核对学生版题面、教师版逐题解答以及所用教材页码和作业记录。
3. 核对草稿没有进入 QQ 交付队列。用「复制 Markdown 草稿」在本地继续编辑或排版。

## 定时任务验收 09

1. 在「定时任务」找到继承的备课计划。再新建一个「实验说明」，设置北京时间、提示词和允许的工具，然后保存。
2. 到点从「后台活动」查看模型实际调用的工具，从「运行任务」查看生成的 Markdown。修改时间或移除计划后，重新打开列表确认配置已保存。
3. 如需依赖最新进度，为任务填写已授权的教师 QQ。已有进度过期而且资料不足时，教师可私信回复「本周讲到……」。工作台显示更新时间与来源。

## 名单验收 17

1. 选择测试课程，使用含「姓名」表头的 XLSX 或 UTF-8 CSV。把文件附在 DSH 助教会话里并指定课程，或选择课程后直接发给助教 QQ 私聊。核对工作台的课程名单。
2. 要求删除一名学生，确认前重新查看名单。DSH 通过确认卡批准，QQ 则通过同一教师账号回复助教给出的一次性指令。
3. 核对确认后名单、旧作业记录和其他课程。
