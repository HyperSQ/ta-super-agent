# 学生查询本人作业情况

状态：已实现。作业统一通过课程邮箱提交；学生用**日常语言**问作业、分数、延期或自己的提交内容，答疑 Worker 判断意图后调用工具，只返回提问者本人的记录。

## 学生怎么说都行

不需要记任何命令。答疑 Worker 先理解意图，再挑工具：

| 学生会说 | 调用的工具 |
|---|---|
| “我第 3 次作业交了吗？多少分？” | `my_coursework` |
| “还有什么作业没交 / 第 4 次作业什么时候截止？” | `list_assignments` + `my_coursework` |
| “我第 3 题是不是写错了？” | `read_my_submission` 看本人附件 |
| “老师我生病了，第三次作业能延到 12 月 5 日吗？” | `request_extension` 建待审批申请 |
| “作业怎么交？” | 直接回答：发课程邮箱 |

`/assignments`、`/extension` 仍然可用，但只是兼容别名，不再是必经入口。

## 为什么放在工具里

学生的问题是自然语言，形态很多。做成工具比做关键词匹配稳：模型先取到结构化事实，再组织回答；关键词匹配容易把“交集”“延期收敛”这类数学词误判成事务查询。

工具本身不做自然语言理解，只做三件事：确认是私聊、确认问的是本人、按课程返回本人数据；延期工具还会校验截止时间必须晚于全班截止，并进入教师待审批。

## 能查到什么

| 字段 | 来源 |
|---|---|
| 提交次数、最近提交时间、是否迟交 | `coursework_requests`（`state='accepted'`，来自邮箱登记） |
| 个人延期（已批准）与有效截止 | `assignment_extensions` |
| 延期申请（待审批） | `coursework_requests`（`kind='extension'`，`state='pending'`） |
| 线下分数与登记时间 | `offline_submissions` |
| 作业标题与全班截止 | `coursework_assignments`（仅 `studentVisible=1`） |

迟交按“最近一次提交时间 > 有效截止（个人延期与全班截止取较晚者）”判断；个人延期被撤销后，有效截止回到全班截止。

## 身份从哪来

作业走邮箱后，系统不会从邮件里自动拿到学生的 QQ，因此绑定由教师完成一次。教师可以直接说“把 QQ 12345 绑定到张三”，也可以发 `/bind 12345 张三`。
教师私聊助教发送，程序校验姓名在名单内、QQ 未被绑定到其他姓名、姓名未被其他 QQ 占用，然后写入 `coursework_qq_students`。

没有绑定就只返回一句说明，告诉他请老师绑定，不猜姓名、不按群昵称匹配。

## 查看自己交的内容

学生问“我交的那份哪里错 / 怎么改”时，答疑 Worker 调用 `read_my_submission`：

| 参数 | 作用 |
|---|---|
| `assignmentId` | 必填，先 `list_assignments` 或 `my_coursework` 拿到 |
| `fileIndex` | 不填只返回附件列表；填了才打开具体文件 |
| `page` | PDF 的页码，默认第 1 页 |

- 图片直接交给视觉模型看；PDF 用 `pdftoppm` 渲染指定页；txt/md 直接读文本。
- 渲染器不可用或文件类型不支持时，如实说“看不到”，请学生发关键页截图，不凭空点评。
- 只返回**本人最近一次已登记提交**，其他人、未登记、草稿都不会出现。

## 边界

- **只在私聊**：群聊里调用会被拒绝，模型会请学生私聊。个人分数、提交状态与提交内容不进入群。
- **只查本人**：`actor` 必须等于任务发起者；返回结构里没有其他学生、没有名单、没有邮箱或附件。
- **只读**：查询不登记、不撤回、不改延期；发现记录不对时，学生找教师核对，或在邮箱里重新提交。
- **不改正式记录**：查询不会产生提交、成绩或延期记录，也不写学习记忆。
- **私信不交作业**：`/submit` 只返回“请通过课程邮箱提交”的提示，不创建提交记录。

## 验收

`tests/student-coursework.test.ts`、`tests/student-submission.test.ts` 覆盖：本人提交/迟交/分数/延期、他人记录不出现、未绑定给说明、群聊拒绝、查看图片/PDF/文本、无渲染器诚实说明、教师自然语言或 `/bind` 绑定与冲突拒绝、学生自然语言申请延期进入待审批。

可重复轨迹：

1. 教师在课程私聊说“把 QQ 12345 绑定到张三”，助教确认绑定。
2. 该生私聊问“我第 3 次作业交了吗，多少分”，助教回答提交次数、时间、是否迟交与分数。
3. 该生接着说“我第 3 题是不是写错了”，助教读取其提交图片并针对该处回答。
4. 该生说“我生病了，第三次作业能延到 12 月 5 日吗”，助教确认作业与时间后创建待审批申请，教师在工作台审批。
5. 另一名学生问同样问题，只看到自己的记录；在群里问分数则被请去私聊。
