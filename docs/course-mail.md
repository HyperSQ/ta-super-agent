# 作业邮箱

在工作台选择课程，打开「作业邮箱」。USTC Mail 使用完整的邮箱地址及客户端专用密码。IMAP 和 SMTP 服务器均为 `mail.ustc.edu.cn`，对应 TLS 端口 993 和 465。工作台可套用这组参数，也可填写其他提供商的 IMAP TLS 与 SMTP TLS/STARTTLS 参数。其他邮箱需要支持客户端密码登录。

- 建议专用收件文件夹。每门课使用不同邮箱或不同 IMAP 文件夹。按主题前缀匹配，默认「作业」。保存后发测试邮件，例如「作业 第 3 次 学生甲」。首次配置只收保存后到达的邮件。
- 「测试连接」检查收件文件夹和 SMTP 登录，不发测试邮件。「收取新邮件」立即检查；启用定时收取后，后台每 30 秒轮询一个课程邮箱。初版每次最多归档一封匹配邮件。服务不会改动邮件的已读标记。
- 邮件归档后由 Router 派发作业处理任务。开启本课的「自动登记提交并生成批改结果」后，主题符合「作业 <作业名> <姓名>」且唯一匹配已发布作业与名单的邮件会自动登记并排队批改。主题中姓名用于归属候选，审核回信时可核对发件身份。其余邮件可在工作台查看候选后手动登记。发布作业或修改名单后，已收邮件可点「重新匹配」。用 IMAP 原始收件时间判定迟交并计入提交次数，已登记记录出现在「提交与延期」。
- 开启本课的「批改完成后自动登分」后，合法评分结果和正式成绩会一起保存，只有当前作业版本及该学生的最新提交可以登分。这个开关默认关闭，发回信仍按教师审核流程。
- 收件时不发自动回执。登记后可手动编辑反馈并回复原发件人。若 SMTP 结果不明，请通过邮箱确认实际发送情况；系统不会因为超时自动重发。
- 支持单封邮件最多 3 个附件、单个 4 MB，邮件原件最多 12 MB。归属确认后可点「生成草稿」。评分细则每行填写「评分点 | 整数满分 | 判分依据」，支持邮件正文、UTF-8 文本附件和用 `pdftotext` 提取的 PDF。得分需要作答原文支持，总分由程序相加。新提交或作业改版后，旧草稿不能用来回信。扫描件 OCR 仍待接入。

服务端依赖 Python 3.9 或以上，可配置 `TA_MAIL_PYTHON`。专用密码加密存入 SQLite，API 不回显。迁移邮箱配置时需同时备份数据库与同目录的 `<数据库名>.mail-key`，密钥文件仅供服务账号读取。使用普通密码或客户端专用密码取决于提供商。校外连接受邮箱提供商网络策略约束。
